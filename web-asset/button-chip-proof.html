Token Mapping

Geometry and radius reference notes

Button geometry

radius-B -> --portal-radius-button -> var(--radius-3)

All button variants keep the same radius, min/max sizing, border width, font rhythm, and icon gap.

Chip geometry

radius-C -> --portal-radius-chip -> var(--radius-2)

Chips keep a tighter radius and smaller vertical profile so they do not collapse into the button family.

Theme immutability

The light and dark review panels use the same button and chip palette. No dimming, muting, or alternate dark-mode skin is applied.
