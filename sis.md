- Shared-theme token policy is nearest-neighbor first: consume the closest existing shared semantic role before adding anything new, and add a new shared token only when a real semantic gap remains after that pass. Do not recreate page-local token ladders or alias shims when the shared theme already has an acceptable role.
- Student portal and parent portal keep their critical grade/quarter overrides on-page after vendor CSS so dark-mode row tinting and quarter-board/button layout stay stable; the shared theme still owns the central tokens behind those overrides.
- Student points and the shared admin login shell keep local CSS effectively structural-only, with a fail-closed theme allowlist test guarding against page-local color reintroduction outside the explicit critical override fences.
- `portal-hub.html` remains the main outstanding visual centralization gap; `grades-tabulator.html` should stay on shared theme roles for color semantics, with page-local CSS limited to structure, spacing, sizing, and Tabulator-specific behavior.
- Admin critical CSS is now generated by `tools/extract-critical-css.mjs` as complete, ID-selector-safe PostCSS rule nodes in `web-asset/admin/student-admin.critical.css`; the shared and full admin stylesheets remain source-owned and are not split by raw byte ranges.
- The selector-only critical CSS experiment is retained as a generated artifact for analysis, but it is not used for the admin first paint. Dev and the test mirror use blocking full shared/admin stylesheets until a real above-the-fold renderer can produce a visually stable critical sheet; the test mirror's static asset path is served by the sites-available Nginx vhost.
- Best-fit future performance workflow: use the existing Playwright package's Chromium CSS/JS coverage over authenticated, representative portal flows, then validate with Lighthouse. Use coverage to guide page/island splitting and candidate CSS extraction; do not auto-delete shared selectors from one coverage run. Treat PurgeCSS only as a review artifact with an explicit dynamic-selector safelist, never as an unattended production rewrite.
